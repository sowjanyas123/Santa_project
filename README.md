# 🎁 Secret Santa Assignment 🎅

## **Overview**
This project automates the **Secret Santa** assignment for employees. Given an employee list and last year's assignments, it generates new pairs while ensuring:
- No employee is assigned to themselves.
- No employee gets the same secret child as last year.
- Each employee gets exactly one secret child.
- Every secret child is unique.
